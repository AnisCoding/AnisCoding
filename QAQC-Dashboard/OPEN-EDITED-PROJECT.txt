DIRAB QA/QC — EDITED POWER BI PROJECT

OPEN AND SAVE AS PBIX
1. Extract this ZIP completely into a new folder on Windows.
2. Open RCRC DIRAB.pbip in a current Power BI Desktop installation.
3. Refresh. Sign in to your existing SharePoint source with your Organizational account if prompted.
4. Select the QA/QC, QA/QC Design Reviews, or QA/QC SLA Scorecard page (the navigation buttons also connect these pages).
5. File > Save As > Power BI files (*.pbix). Save as RCRC DIRAB QAQC.pbix.

This is an edited PBIP project, NOT a PBIX binary. No file has merely been renamed to PBIX.

METRIC DEFINITIONS
Closure excludes withdrawn items. SLA excludes missing closure dates. Open actions are not overdue counts. Design pages show SHD/RFI review status, not planned-versus-actual design completion. SLA uses workbook Block 1; contradictory MIR counts/day limits in Block 12 are not used. Percentages are recomputed from numeric counts, not the imported text percentage columns.

INTERACTION
The source tables contain aggregate summaries at different grains. Charts do not imply record-level drill-through or cross-table date filtering. New charts keep drillFilterOtherVisuals disabled to avoid misleading interactions between independent aggregate tables.
